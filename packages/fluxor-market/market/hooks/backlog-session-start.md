# backlog-session-start: Start From the Board

Before you pick any work, follow the `backlog` skill's "A session, in order", with the project and
the machine name its `config/backlog.json` gives: who is working on what, the cards this machine left
unfinished (finish those first), the cards a person edited, the walls waiting on a person, and only
then the next card. Pass the machine name on every backlog call that takes one.
